#CS-210 Programming Languages

Corner Grocer Project

Southern New Hampshire University | CS-210

Project Summary

The Corner Grocer project was developed using C++ to help a grocery store analyze how frequently customers purchase specific items. The program reads a text file containing grocery items and calculates their purchase frequencies. Users can search for individual items, display a complete list of item frequencies, or view a histogram representing the results. The program also saves frequency data to a backup file.

What Did I Do Particularly Well?

One aspect I believe I handled well was organizing the program into functions and using object-oriented programming principles. I also implemented a menu that allows users to navigate between different options. These features helped make the application organized and easier to use.

Where Could I Enhance My Code?

I could improve my code by expanding input validation and error handling. For example, I could provide clearer feedback when a user enters an invalid menu selection or when an input file cannot be opened. These improvements would make the program more secure, reliable, and user-friendly.

What Did I Find Most Challenging?

One of the most challenging parts of this project was correctly reading data from a file and calculating the frequency of each grocery item. I worked through these challenges by reviewing course materials, testing different parts of the program, and using debugging techniques to identify and correct errors. This experience helped strengthen my problem-solving skills and taught me the importance of testing my code.

What Skills Will Transfer to Future Projects?

This project helped me develop skills in C++ programming, object-oriented design, file handling, debugging, and problem-solving. These skills will be useful in future computer science courses and professional software development projects. I also gained experience breaking larger programming problems into smaller, manageable tasks.

How Did I Make My Program Maintainable, Readable, and Adaptable?

I focused on organizing the program into functions, using descriptive names, and adding comments to explain important sections of the code. Separating the program’s responsibilities makes it easier to understand, troubleshoot, and modify. This structure also allows future improvements without requiring the entire program to be rewritten.
